# 移動で位置を入れ替える (Swap Places by Default)

味方NPCに向かって移動すると、メニューを開かずに**位置を入れ替える**MODです（移動力200を消費）。

- いつものメニューを開きたいときは、アクションメニューの「次の1回だけNPCメニューを開く」を選んでから、NPCに触れてください（移動、または`E`で調べる）。
- 相手が味方でない・眠っている、どちらかが騎乗中、隣接していない、相手のマスに罠がある、乗り物の上、自動移動中のときは入れ替えず、本体のメニューを開きます。

## 設定

`main.lua` 冒頭の `mod.cfg` で、移動力（`move_cost`）、対象を味方に限るか（`require_ally`）、罠・乗り物を避けるか（`avoid_traps` / `avoid_vehicles`）などを変えられます。ゲーム中でもデバッグメニューの **Reload Lua Code** で反映されます。

## 注意

- **Lua対応ビルドが必要です**（`lua_api_version: 2`）。
- 既存のワールドに追加・削除できます。セーブデータには何も書き込みません。
- 「次の1回だけ」はセーブされず、ゲームを再開すると解除されます。
