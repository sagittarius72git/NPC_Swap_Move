# 移動で位置を入れ替える (Swap Places by Default)

味方NPCに向かって移動したときの既定の動作を、メニュー表示から**位置の入れ替え**に変えるMODです。
狭い廊下で仲間とすれ違うたびにメニューを開いて「s」を押す手間が無くなります。

## 使い方

- **味方に向かって移動する** → その場で位置が入れ替わります（移動力200を消費）。
- **いつものメニューを開きたいとき** → アクションメニューから
  「次の1回だけNPCメニューを開く」を選び、そのあとNPCに触れる（移動する、または`E`で調べる）と、
  従来どおりのメニューが開きます。この項目はキー設定で好きなキーに割り当てられます。

## 入れ替えが起きない場合

次のいずれかに当てはまるときは、何もせず本体のメニューを開きます。

- 相手が味方でない（商人や見知らぬNPCなど）、または眠っている
- 自分か相手が騎乗している
- 隣接していない（`E`で離れた相手を操作したときなど）
- 相手のマスに罠がある
- どちらかのマスが搭乗可能な乗り物の上にある
- 自動移動中

罠と乗り物を避けているのは安全のためです。本体の「Swap positions」は入れ替え前に危険確認を出しますが、
この確認はLuaから呼べません。また、NPCの搭乗状態を設定する関数もLuaに無いため、
乗り物の上での入れ替えは正しく処理できません。どちらも「入れ替えずにメニューを開く」ことで回避しています。

## 設定

`main.lua` の冒頭にある `mod.cfg` を書き換えてください。ゲーム中に書き換えて
デバッグメニューの **Reload Lua Code** を実行すれば即反映されます。

```lua
mod.cfg = {
  move_cost = 200,      -- 入れ替えに使う移動力（本体と同じ200）
  require_ally = true,  -- false にすると敵対していないNPC全員が対象
  avoid_traps = true,   -- 相手のマスに罠があるときは入れ替えない
  avoid_vehicles = true,-- 乗り物の上では入れ替えない
  announce = true,      -- メッセージを出す
  debug = false,        -- 詳細をデバッグログに出す
}
```

## 注意点

- **Lua対応ビルドが必要です**（`lua_api_version: 2`）。公式のWindows配布版は対応しています。
- 既存のワールドに後から追加・削除できます。セーブデータには何も書き込みません。
- 「次の1回だけ」スイッチの状態はセーブされません。ゲームを再開すると解除された状態に戻ります。
